# NyxDay n8n Templates

Free, open-source n8n workflow templates by [NyxDay Inc.](https://nyxday.com).

## Available templates

- [Smart Customer Inquiry & Follow-Up Manager](templates/smart-customer-inquiry/README.md)

Future templates will use the same `templates/<template-slug>/` layout, including `quote-approval` and `client-onboarding`. They intentionally have no placeholder workflows yet.

## Development

Run `npm test` with Node.js 20+ to validate the workflow package. These tests validate exported files and deterministic business rules; they are not a substitute for testing in n8n.
