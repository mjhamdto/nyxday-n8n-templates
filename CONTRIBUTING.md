# Contributing

Thanks for improving NyxDay templates. Keep templates importable without secrets, prefer documented built-in n8n nodes, and include setup, configuration, tests, and synthetic examples. Run `npm test` before opening a pull request. Never commit credentials, production URLs, customer data, or execution exports.

Changes that alter a workflow must update its documentation and tests. Test the import in an isolated n8n instance when one is available; record the version and result in the pull request.
