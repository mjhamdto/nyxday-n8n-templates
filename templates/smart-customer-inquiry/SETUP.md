# Setup

## Mandatory setup

1. In a non-production n8n project, import `workflow.json` from **Workflows → Import from File**. Keep it inactive. If you imported an earlier copy of this template, import this corrected file as a new workflow; n8n does not automatically update imported workflows.
2. Open **Data Tables** in the same project and create a table named `customer_inquiries`. Add every column shown below as a text-compatible column. Copy its ID from the table URL/UI.
3. In all six Data Table nodes, replace `REPLACE_WITH_DATA_TABLE_ID` with that table ID. Keep the column names exact so automatic mapping works.
4. Open **Normalize, validate & classify (CONFIG HERE)** and update the plain `cfg` values. Set the workflow timezone in workflow settings.
5. Create an SMTP credential in n8n. Select it in both Send Email nodes, then replace the example sender and internal recipient addresses. Do not use the submitted customer's address as an internal recipient.
6. To start an intake test, select **Customer inquiry form** and click **Execute step** (or **Execute workflow**). Submit the Test URL opened by n8n. This is the upper branch. The lower scheduled branch cannot be started from the form; execute **Hourly follow-up check** only after a test row exists.
7. In **Data Tables**, change a row status to `Acknowledged`, `In progress`, `Waiting for customer`, `Resolved`, or `Closed`. Update `last_activity_at` when a person acts. Do not reopen Closed records.
8. For a reminder test, set an open test row's `follow_up_due_at` in the past and `reminder_count` below 3, then manually execute from **Hourly follow-up check**. Confirm the reminder and updated count.
9. Publish the workflow and use the Form Trigger's production URL only after the preceding checks pass. Schedule triggers require publishing.

## Table schema

| Column | Data Table type | Purpose |
| --- | --- | --- |
| `inquiry_id` | String | Human-readable unique best-effort identifier. |
| `full_name`, `email`, `phone`, `company` | String | Contact fields; keep access restricted. |
| `category`, `subject`, `message`, `preferred_contact_method` | String | Inquiry content and stated preference. |
| `consent` | Boolean | Privacy acknowledgement received with the submission. |
| `priority`, `status`, `assigned_owner`, `source` | String | Operational routing and lifecycle. |
| `submitted_at`, `last_activity_at`, `follow_up_due_at` | Date | Required ISO-8601 timestamps generated by the workflow. |
| `last_reminder_at`, `resolution_at` | Date | Optional timestamps. Leave cells empty in the UI; the workflow sends `null` until a value exists. |
| `reminder_count` | Number | Starts at `0`; increments after a successful or failed reminder attempt. |
| `notification_state`, `processing_state`, `error_state` | String | Processing/audit state. |
| `duplicate_of`, `dedupe_key` | String | Duplicate handling; treat dedupe key as personal data. |

Do **not** add `duplicate_window_start` to the Data Table. It is a temporary query helper, removed by **Remove temporary duplicate-window value** before a record is stored.

## Optional hardening

- Put the public form behind your site, reverse proxy, CAPTCHA/WAF, rate limit, and privacy notice. **Ignore Bots** is enabled but is not an abuse-prevention system.
- Use a dedicated least-privilege SMTP account. Restrict project membership because Data Tables are project-visible.
- Set a data-retention/deletion procedure. Export then securely delete old rows after the required retention period.
- Add a separate Error Trigger workflow to notify an operator using an internal, non-PII execution reference. Do not make it call this workflow recursively.

## Recovery

Storage errors stop the relevant execution before an alert is sent. SMTP nodes use continue-on-fail so the saved row is retained and its notification state becomes `failed` / `reminder_failed`. Inspect **Executions**, correct the credential or table issue, read the current row, then retry only the failed alert/reminder action. Do not retry a whole intake execution blindly without checking whether a row already exists.
